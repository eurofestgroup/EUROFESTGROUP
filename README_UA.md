# Актуальне оновлення: усі 8 покращень вигляду та зручності

1. Плавні короткі переходи між сторінками. У сучасних браузерах працює анімація переходу; в інших — легке затемнення. Посилання, нові вкладки, переходи до розділів і кнопка «Назад» зберігають звичну поведінку.
2. Фото розгортається зі своєї мініатюри у великий перегляд і повертається до відповідної картки. Поки оригінал завантажується, видно мініатюру. Стрілки, свайпи, Escape, кнопка закриття та відкриття оригіналу працюють як раніше.
3. Оновлена типографіка: локальні стиснені шрифти з українськими й англійськими символами, виразні заголовки та акуратні переноси. Шрифти входять до папки `assets/fonts`; зовнішній сервіс шрифтів не потрібен.
4. На телефоні — нижня скляна панель «Головна / Події / Новини / Фото». Врахована нижня безпечна зона екрана; в кінці сторінки залишено місце, щоб панель не закривала останні кнопки. У перегляді фото або деталей події вона ховається.
5. Спробна журнальна розкладка галереї: великі акцентні кадри між меншими фотографіями. Порядок фотографій і поступове завантаження збережені. Цю зміну можна вимкнути окремо.
6. Спробний відеофон на головній. Це 12-секундна петля з наявного зображення вантажівок і плавного руху камери. WebM — приблизно 431 КБ, MP4 — приблизно 671 КБ; браузер завантажує один формат. Відео починає завантажуватися через 8 секунд лише на ПК, коли перший екран видно. На телефонах і планшетах шириною до 1100 px, при вимкнених ефектах, зменшеному русі, економії трафіку чи повільному з’єднанні залишається звичне фото. Відео без звуку; на іншому розділі або у фоновій вкладці воно зупиняється. Цю зміну можна вимкнути окремо.
7. Скляні кнопки м’яко реагують на натискання й короткий світловий відблиск. Працює мишею, дотиком і клавіатурою.
8. Власна сторінка `404.html` у стилі EUROFEST: фон, номер 404, дві мови й кнопки повернення на головну або до подій. На GitHub Pages вона також працює для помилкових адрес із кількома вкладеними частинами.

Звичне скло та чорно-червона палітра збережені. На головній як і раніше максимум **6 подій** і **6 новин**. Повні списки, архів, DLC, інформація з Discord/TruckersMP, оригінали фотографій та кеш 100 фото залишаються на своїх місцях. Кнопка вимкнення ефектів і системна опція зменшеного руху враховуються новими анімаціями.

## Що і куди закинути — лише GitHub

1. Завантаж і розпакуй `EUROFEST_GROUP_website.zip`.
2. Відкрий папку `EUROFEST_GROUP/github-pages`.
3. Відкрий свій репозиторій сайту на GitHub → **Add file → Upload files**.
4. Завантаж **увесь вміст** `github-pages` у корінь репозиторію, з якого публікується GitHub Pages: `index.html`, `events.html`, `news.html`, `photos.html`, `archive.html`, новий `404.html`, `sw.js`, папку `assets` і нову папку `media`. Завантажуй вміст, а не зовнішню папку `github-pages`. Усередині `assets` обов’язково має залишитися папка `fonts`. Якщо публікуєш із папки `docs`, завантаж цей вміст саме в `docs`.
5. Натисни **Commit changes** й дочекайся завершення GitHub Pages deployment.
6. Відкрий сайт із **Ctrl+F5**. Для перевірки відео відкрий головну на ПК, залиш її на першому екрані приблизно на 8 секунд і переконайся, що ефекти ввімкнено. На телефоні має бути статичний фон і нижня навігація. Перевір обидві мови та галерею.

**Для цього оновлення на хостинг нічого закидати й перезапускати не потрібно.** Якщо попереднє оновлення вже працює, залиш БД, конфіг хостингу, API і лаунчер як є. Папка `hosting` в архіві збережена для повного комплекту.

## Якщо напишеш «5 відміна» або «6 відміна»

Відкрий на GitHub файл `assets/config.js`, зміни лише потрібний перемикач і збережи commit:

| Що повернути | Зміна |
|---|---|
| Попередня рівна сітка фотографій — «5 відміна» | `galleryMagazine: false` |
| Попередній статичний фон — «6 відміна» | `heroVideo: false` |

Перемикачі незалежні. Можна вимкнути лише №5, лише №6 або обидва. Решта шести покращень продовжить працювати. Щоб знову ввімкнути, поверни `true`. Адресу `apiUrl` під час цього не змінюй. Після deployment онови сторінку.

Для звичайного сайту GitHub Pages із адресою `https://ім’я.github.io/назва-репозиторію/` сторінка 404 визначає папку автоматично. Якщо колись зробиш сайт у самому корені `https://ім’я.github.io/`, у `404.html` встанови `const manualBase = '/';`. Для іншого хостингу з нестандартною вкладеною папкою вкажи її у цій самій змінній.

# EUROFEST GROUP — просте підключення до БД

У цьому комплекті всього дві частини:

| Що | Куди |
| --- | --- |
| Вміст папки `github-pages` | У GitHub-репозиторій `eurofestgroup/efgo.vtc` |
| `hosting/site_events_api.py` | На хостинг, у ту саму папку, де `eurofest_convoys.db` |

Схема: сайт на GitHub Pages звертається до HTTPS-адреси твого хостингу, один Python-файл читає актуальні записи БД і повертає події. Дизайн галереї залишається в самому сайті. Налаштування галереї на сервері більше не потрібні.

Твоя HTTPS-адреса та порт уже підставлені:

- `https://i6t4udxoj3.apps.bot-hosting.cloud`
- порт `25710`
- сайт `https://eurofestgroup.github.io/efgo.vtc/`

Потрібен один початковий запуск скрипта на хостингу. Надалі достатньо редагувати події своїм Discord-ботом — сайт підхоплює зміни сам.

## Крок 1. Розпакуй архів

Скачай `EUROFEST_GROUP_website.zip` і розпакуй. Усередині папки `EUROFEST_GROUP` побачиш `github-pages`, `hosting` та цю інструкцію.

## Крок 2. Завантаж один файл на хостинг

1. Відкрий панель свого хостингу.
2. Перейди у вкладку «Файли».
3. Знайди папку, де лежить **твоя існуюча** `eurofest_convoys.db`. Зазвичай це коренева папка `/home/container`.
4. З папки `hosting` в архіві завантаж **сам файл** `site_events_api.py` у цю папку.
5. Перевір, що `site_events_api.py` і `eurofest_convoys.db` лежать поруч.

Папку `hosting` цілком закидати не треба: скрипт автоматично шукає БД саме поруч із собою. У комплекті немає нової БД — наявну не замінюй.

Приклад правильних шляхів:

- `/home/container/site_events_api.py`
- `/home/container/eurofest_convoys.db`
- `/home/container/main.py` — це лише приклад назви твого вже наявного файла запуску.

## Крок 3. Один раз налаштуй запуск разом із ботом

1. Відкрий вкладку «Запуск».
2. Подивись, який Python-файл запускається зараз. Це може бути `main.py`, `watchdog.py`, `run.py` або інша назва.
3. Збережи собі поточну команду, щоб знати точну назву файла.
4. У новій команді вкажи `site_events_api.py`, а після `--bot` — **назву свого попереднього файла запуску**.

Наприклад, якщо зараз запускається:

```sh
python3 main.py
```

нова команда:

```sh
python3 site_events_api.py --bot main.py
```

Якщо зараз запускається `watchdog.py`, команда буде:

```sh
python3 site_events_api.py --bot watchdog.py
```

Це приклади. Не пиши `main.py`, якщо такого файла в тебе немає — використовуй свою поточну назву. Вміст бота змінювати не потрібно: новий файл запускає його сам, а читання БД працює поруч у фоновому потоці. Якщо твій файл запускає декілька ботів, він продовжує це робити.

Якщо поточна команда має аргументи, передай їх після назви файла через `--`. Приклад:

```sh
python3 site_events_api.py --bot main.py -- --example value
```

Цей рядок потрібен лише для ботів, які вже мали аргументи. Зазвичай достатньо команди без додаткових аргументів.

5. Збережи команду й перезапусти сервер.
6. У консолі має з'явитися повідомлення `Галерея працює на порту 25710`. Далі мають піти звичайні повідомлення твого бота.

Python має бути версії 3.9 або новішої. Для самого скрипта не потрібно додавати пакети в `requirements.txt`. Порт береться зі змінної `SERVER_PORT` панелі; резервне значення — 25710. HTTPS уже забезпечує адреса `apps.bot-hosting.cloud`, яку ти показав на скриншоті.

Якщо панель дозволяє змінювати тільки поле «файл запуску», але не всю команду або її аргументи, надішли скриншот вкладки «Запуск». За ним можна буде вказати точні поля. Не вписуй цілу команду в поле, яке приймає лише назву файла.

Галерея показує `SCHEDULED`, `PUBLISHED` та `STARTED`, сортує за датою і часом виїзду. Чернетки, скасовані та завершені події не показуються. Через три години після виїзду подія зникає з галереї; якщо час виїзду не заданий — наприкінці її дня. Час — за Києвом, з урахуванням літнього й зимового часу.

Обкладинка — карта маршруту з БД. Якщо її немає або зображення недоступне, використовується фонове зображення колони. У деталях можна відкрити маршрут і слот, якщо вони додані до БД.

Скрипт тільки читає БД. Таблиці логів, нагадування та інші службові записи не передаються на сайт. Окремі налаштування галереї, токени та нові пакети для API не потрібні.

## Якщо не працює

| Що бачиш | Що перевірити |
| --- | --- |
| `database_found:false` | Чи лежать скрипт і БД в одній папці |
| `database_unavailable` | Шлях/файл БД та повідомлення в консолі хостингу |
| «Відповіді на порту немає» | Чи запущено нову команду і чи слухає вона 25710 |
| `Address already in use` | На цьому порту вже працює інший API; потрібен лише один екземпляр |
| Бот не знаходиться | Назву після `--bot` потрібно взяти зі старого запуску |
| API працює, але сайт старий | Дочекайся завершення публікації GitHub Pages та онови сторінку через Ctrl+F5 |
| Сайт пише, що розклад недоступний | Спочатку перевір обидва API-посилання з кроку 4 |

Якщо ти вже запускав попередню версію API, використовуй новий `site_events_api.py` замість неї. Попередня папка `eurofest_gallery` для цього комплекту не потрібна.

Цей комплект ще не встановлено на твій віддалений сервер і не завантажено у GitHub. Локально перевірено читання наданої БД, оновлення даних без перезапуску, сортування, часові пояси, роботу фільтрів і деталей, запуск існуючого бота та приховування службових даних. Повну браузерну перевірку в цьому середовищі не проводили.


## Якщо навколо кнопок або карток з’являються чорні прямокутники

Оновлений `assets/glass.css` використовує внутрішні відблиски замість великих
зовнішніх тіней. Щоб оновити вже опублікований сайт, замініть лише
`assets/glass.css` у своєму репозиторії та збережіть зміни через Commit changes.
Після публікації GitHub Pages натисніть Ctrl+F5 на сторінці сайту.

Якщо артефакти залишилися, кнопка «Ефекти: увімкнено» внизу сайту тепер
повністю вимикає тіні та CSS-фільтри. Це запасний режим відображення;
читання подій із бази працює так само.


## Оновлення скляного стилю EUROFEST

Додано прозорі скляні поверхні, округлі кнопки, плаваючу навігацію,
внутрішні світлі краї та відблиски, які реагують на курсор.
На телефоні поверхні мають статичні відблиски без відстеження пальця.
Великі зовнішні тіні для цього ефекту не використовуються.

Для вже опублікованого сайту замініть `index.html` у корені GitHub-репозиторію
і два файли у папці `assets`: `glass.css` і `app.js`. Збережіть точні назви файлів,
натисніть Commit changes, дочекайтеся публікації GitHub Pages і натисніть Ctrl+F5.
Якщо раніше вимикали ефекти, увімкніть їх кнопкою внизу сторінки.

Перемикач «Ефекти» вимикає всі тіні, blur та рухомі відблиски.
Сайт також враховує системні налаштування зменшення руху, а в браузерах,
які підтримують `prefers-reduced-transparency`, — зменшення прозорості.
Це оновлення стосується файлів сайту на GitHub.

`index.html` оновлює посилання на CSS/JS, щоб браузер завантажив новий стиль,
і спрямовує кнопку «Нагору» до початку сторінки.
