# EUROFEST GROUP — просте підключення до БД

У цьому комплекті всього дві частини:

| Що | Куди |
| --- | --- |
| Вміст папки `github-pages` | У GitHub-репозиторій `eurofestgroup/efgo.vtc` |
| `hosting/site_events_api.py` | На хостинг, у ту саму папку, де `eurofest_convoys.db` |

Схема: сайт на GitHub Pages звертається до HTTPS-адреси твого хостингу, один Python-файл читає актуальні записи БД і повертає події. Дизайн галереї залишається в самому сайті. Налаштування галереї на сервері більше не потрібні.

Твоя HTTPS-адреса та порт уже підставлені:

- `https://i6t4udxoj3.apps.bot-hosting.cloud`
- порт `25710`
- сайт `https://eurofestgroup.github.io/efgo.vtc/`

Потрібен один початковий запуск скрипта на хостингу. Надалі достатньо редагувати події своїм Discord-ботом — сайт підхоплює зміни сам.

## Крок 1. Розпакуй архів

Скачай `EUROFEST_GROUP_website.zip` і розпакуй. Усередині папки `EUROFEST_GROUP` побачиш `github-pages`, `hosting` та цю інструкцію.

## Крок 2. Завантаж один файл на хостинг

1. Відкрий панель свого хостингу.
2. Перейди у вкладку «Файли».
3. Знайди папку, де лежить **твоя існуюча** `eurofest_convoys.db`. Зазвичай це коренева папка `/home/container`.
4. З папки `hosting` в архіві завантаж **сам файл** `site_events_api.py` у цю папку.
5. Перевір, що `site_events_api.py` і `eurofest_convoys.db` лежать поруч.

Папку `hosting` цілком закидати не треба: скрипт автоматично шукає БД саме поруч із собою. У комплекті немає нової БД — наявну не замінюй.

Приклад правильних шляхів:

- `/home/container/site_events_api.py`
- `/home/container/eurofest_convoys.db`
- `/home/container/main.py` — це лише приклад назви твого вже наявного файла запуску.

## Крок 3. Один раз налаштуй запуск разом із ботом

1. Відкрий вкладку «Запуск».
2. Подивись, який Python-файл запускається зараз. Це може бути `main.py`, `watchdog.py`, `run.py` або інша назва.
3. Збережи собі поточну команду, щоб знати точну назву файла.
4. У новій команді вкажи `site_events_api.py`, а після `--bot` — **назву свого попереднього файла запуску**.

Наприклад, якщо зараз запускається:

```sh
python3 main.py
```

нова команда:

```sh
python3 site_events_api.py --bot main.py
```

Якщо зараз запускається `watchdog.py`, команда буде:

```sh
python3 site_events_api.py --bot watchdog.py
```

Це приклади. Не пиши `main.py`, якщо такого файла в тебе немає — використовуй свою поточну назву. Вміст бота змінювати не потрібно: новий файл запускає його сам, а читання БД працює поруч у фоновому потоці. Якщо твій файл запускає декілька ботів, він продовжує це робити.

Якщо поточна команда має аргументи, передай їх після назви файла через `--`. Приклад:

```sh
python3 site_events_api.py --bot main.py -- --example value
```

Цей рядок потрібен лише для ботів, які вже мали аргументи. Зазвичай достатньо команди без додаткових аргументів.

5. Збережи команду й перезапусти сервер.
6. У консолі має з'явитися повідомлення `Галерея працює на порту 25710`. Далі мають піти звичайні повідомлення твого бота.

Python має бути версії 3.9 або новішої. Для самого скрипта не потрібно додавати пакети в `requirements.txt`. Порт береться зі змінної `SERVER_PORT` панелі; резервне значення — 25710. HTTPS уже забезпечує адреса `apps.bot-hosting.cloud`, яку ти показав на скриншоті.

Якщо панель дозволяє змінювати тільки поле «файл запуску», але не всю команду або її аргументи, надішли скриншот вкладки «Запуск». За ним можна буде вказати точні поля. Не вписуй цілу команду в поле, яке приймає лише назву файла.

Створюєш, редагуєш або видаляєш події через наявного Discord-бота. Вони зберігаються у твоїй `eurofest_convoys.db`, а сайт сам читає актуальний список.

Обкладинка — карта маршруту з БД. Якщо її немає або зображення недоступне, використовується фонове зображення колони. У деталях можна відкрити маршрут і слот, якщо вони додані до БД.

Скрипт тільки читає БД. Таблиці логів, нагадування та інші службові записи не передаються на сайт. Окремі налаштування галереї, токени та нові пакети для API не потрібні.

## Якщо не працює

| Що бачиш | Що перевірити |

| `database_found:false` | Чи лежать скрипт і БД в одній папці |

| Сайт пише, що розклад недоступний | Спочатку перевір обидва API-посилання з кроку 4 |

## Оновлення скляного стилю EUROFEST

Додано прозорі скляні поверхні, округлі кнопки, плаваючу навігацію,
внутрішні світлі краї та відблиски, які реагують на курсор.
На телефоні поверхні мають статичні відблиски без відстеження пальця.
Великі зовнішні тіні для цього ефекту не використовуються.

Для вже опублікованого сайту замініть `index.html` у корені GitHub-репозиторію
і два файли у папці `assets`: `glass.css` і `app.js`. Збережіть точні назви файлів,
натисніть Commit changes, дочекайтеся публікації GitHub Pages і натисніть Ctrl+F5.
Якщо раніше вимикали ефекти, увімкніть їх кнопкою внизу сторінки.

Перемикач «Ефекти» вимикає всі тіні, blur та рухомі відблиски.
Сайт також враховує системні налаштування зменшення руху, а в браузерах,
які підтримують `prefers-reduced-transparency`, — зменшення прозорості.
Це оновлення стосується файлів сайту на GitHub.

`index.html` оновлює посилання на CSS/JS, щоб браузер завантажив новий стиль,
і спрямовує кнопку «Нагору» до початку сторінки.
